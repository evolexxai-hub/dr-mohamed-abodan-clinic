# Dr. Mohamed Abodan — Rhinoplasty Clinic Website

Static site (HTML + one CSS + GSAP/jQuery/Webflow IX2). No build step.
Run: `python -m http.server 8765` then open http://127.0.0.1:8765/

- Pages: index, about, service, blog, privacy, terms, cookies, licenses, 404
- Theme: `assets/css/clinic.css` (brown/bronze from the clinic logo)
- Booking: WhatsApp `+20 155 556 2162` (lead form + all CTAs)
- Images: scraped from @dr_mohamed_abodan via Apify `apify/instagram-scraper`; originals in `_source/instagram/`
